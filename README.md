# EditTextInImage

**Homepage:** [https://edittextinimage.com/](https://edittextinimage.com/)

Thin reference package for **Edit Text In Image** — a freemium online tool that replaces text in finished images while aiming to keep font, color, size, perspective, and background.

Edit posters, slides, screenshots, and ads without reopening Photoshop. Upload a PNG/JPEG/WebP, enter the original wording and its replacement, then generate. Matching locations are found automatically; draw an area only when needed.

## Install

```bash
pip install edittextinimage
```

## Usage

```python
import edittextinimage as eti
print(eti.HOMEPAGE)       # https://edittextinimage.com/
print(eti.open_homepage())  # returns the URL to open
```
